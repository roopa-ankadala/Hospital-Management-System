🏥 Hospital Management System

📌 Project Overview

The Hospital Management System is a simple web-based application developed to manage patient records. It allows users to add, view, and delete patient information through an interactive interface.

🚀 Features

Add patient details
Automatically generate unique Patient IDs
View patient records in a table
Delete patient records
Responsive user interface

🛠️ Technologies Used

HTML5
CSS3
JavaScript

▶️ How to Run

Clone this repository.
Open the project folder.
Open index.html in your web browser.
